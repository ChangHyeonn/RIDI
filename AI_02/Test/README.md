# 🧪 AI_02 테스트 가이드

AI_02의 LLM 기능을 테스트하기 위한 테스트 코드들입니다.

## 📋 테스트 파일 목록

### 1. `simple_test.py` - 기본 기능 테스트
- 기본적인 LLM 텍스트 처리 기능을 테스트
- 일정 추가, 조회, 삭제 기능 테스트
- 자동화된 테스트 케이스 실행

### 2. `llm_text_test.py` - 대화형 테스트
- 사용자가 직접 텍스트를 입력하여 테스트
- 실시간으로 AI 서버의 응답을 확인
- 상세한 응답 분석 및 포맷팅

## 🚀 테스트 실행 방법

### 1. 환경 설정 확인

먼저 필요한 환경 변수를 설정하세요:

```bash
# OpenAI API 키 설정
export OPENAI_API_KEY="your_openai_api_key_here"

# AI 서버 설정
export AI_SERVER_HOST="0.0.0.0"
export AI_SERVER_PORT="8080"
export AI_SERVER_DEBUG="True"

# LLM 설정
export LLM_TYPE="openai"

# 데이터베이스 설정 (선택사항)
export DB_ENGINE="inmemory"  # 또는 "mongodb"
export MONGO_URI="mongodb://localhost:27017/"  # MongoDB 사용 시
export MONGO_DB="ridi_ai"  # MongoDB 사용 시
```

## 📚 테스트 예시

### 일정 관리 테스트
```bash
# 일정 추가
"내일 오후 3시에 병원 예약이 있어"
"다음 주 월요일 오전 10시에 회의가 있어"

# 일정 조회
"내일 일정이 뭐야?"
"이번 주 일정 알려줘"

# 일정 삭제
"병원 예약 취소해줘"
"내일 회의 삭제해줘"
```

### 일반 대화 테스트
```bash
"안녕하세요"
"오늘 날씨 어때?"
"도움말을 알려줘"
```

### 명확화 요청 테스트
```bash
"일정 추가해줘"  # 시간 정보 없음
"회의 취소해줘"  # 어떤 회의인지 모호함
```

## 🔧 문제 해결

### 1. API 키 오류
```
⚠️  API 키가 설정되지 않았습니다. 기본 응답 모드로 실행됩니다.
   환경 변수 OPENAI_API_KEY를 설정하세요.
```
**해결방법:** `export OPENAI_API_KEY="your_api_key"` 설정

### 2. Import 오류
```
ModuleNotFoundError: No module named 'Processor'
```
**해결방법:** AI_02 폴더에서 실행하세요: `cd AI_02 && python3 Test/simple_test.py`

### 3. 설정 검증 오류
```
❌ 설정 오류:
   - OpenAI 모델 사용 시 OPENAI_API_KEY가 필요합니다
```
**해결방법:** 환경 변수 설정 확인

## 📊 테스트 결과 해석

### 성공적인 응답 구조
```json
{
  "success": true,
  "action": {
    "type": "schedule_add",
    "is_important": true,
    "data": {
      "schedule": {
        "id": "schedule_1234567890",
        "title": "병원 예약",
        "datetime": "2024-01-15 15:00:00"
      }
    },
    "ui_instructions": {
      "screen": "calendar",
      "refresh_data": true,
      "show_confirmation": true
    }
  },
  "text_response": {
    "text": "내일 오후 3시에 병원 예약을 추가했습니다.",
    "display_automatically": true
  }
}
```

### 액션 타입별 의미
- `schedule_add`: 일정 추가
- `schedule_list`: 일정 조회
- `schedule_delete`: 일정 삭제
- `clarification_request`: 명확화 요청
- `general_response`: 일반 대화 응답
